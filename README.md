# RoverMEMS

クラシックミニ(ローバーミニ)のエンジンコンピューター(MEMS)をスマホで診断する、Android用の無料アプリです。エンジン回転数や水温などをリアルタイムで表示したり、燃料ポンプやファンを動かして点検したり、走行中のデータを記録したりできます。

> **開発中のバージョンです**
> 実車(1996年式ミニSPi / MEMS 1.3)で、USBケーブル・Bluetoothの両方で接続できることを確認しています。不具合が残っている可能性があります。

*English: RoverMEMS is a free Android diagnostic app for the Rover Mini's MEMS ECU (tested on MEMS 1.3 SPi). Connect over a USB serial cable or a Bluetooth LE module to view live data, run actuator tests and record logs. The UI can be switched to English.*

## 📥 ダウンロード

[**最新版をダウンロード(APK)**](https://github.com/RoverMEMS/RoverMEMS/releases/latest/download/app-debug.apk)

スマホでこのリンクを開くとアプリのファイルがダウンロードされるので、開いてインストールしてください。「提供元不明のアプリ」の許可を求められたら許可します。

Googleの「Playプロテクト」から「アプリをスキャンのために送信しますか？」と表示されることがあります。Playストア以外から入れたアプリには毎回出る確認で、**「送信する」「送信しない」のどちらを選んでも問題なく使えます**(送られるのはアプリのファイルだけで、走行データなどは送信されません)。

**車がなくても試せます**: アプリの最初の画面で「デモモードで開始」を押すと、サンプルのデータで画面を試せます。

## 🔌 車へのつなぎ方

次のどちらかを用意します。

| 方法 | 必要なもの |
|---|---|
| **USBケーブル** | USBシリアルケーブル(PL2303等)と、スマホの差し込み口(USB-C等)に合わせる変換アダプタ |
| **Bluetooth** | 自作のBluetoothモジュール([作り方](firmware/atom_lite_bridge/README.md))。日本の電波法の認証(技適)を取っている M5Stack ATOM Lite を使います |

つなぎ方の流れ:

1. ケーブルまたはBluetoothモジュールを、車の診断カプラーにつなぐ
2. キーを ON にする(エンジンはかけてもかけなくてもOK)
3. アプリの最初の画面で「USB」または「Bluetooth」を選び、表示された機器をタップする
4. メーターが動き出せば接続完了

Bluetoothの場合、エンジンをかける瞬間に一度接続が切れることがありますが、自動でつなぎ直します。

## 📈 主な機能

- 4種類の表示: シンプル / 詳細 / グラフ / アナログメーター
- 点検(アクチュエータテスト): 燃料ポンプ・ファン・インジェクター・O2センサーのヒーターなどを動かして確認
- 走行データの自動記録: 車につながっている間は自動で記録します(最大50件、古いものから自動で削除)。記録は最初の画面の「保存したログを見る」からグラフで見られます
- 日本語/英語の切り替え

記録したログは、スマホの「ダウンロード」フォルダの中の `RoverMEMS` フォルダに保存されます。[ログ解析ツール](https://rovermems.github.io/RoverMEMS/)で開くと、気になる点を探せます。

## 対応環境

- Android 8.1 以降
- 対象: ローバーミニ SPi(MEMS 1.3 / 1.6)。動作確認は MEMS 1.3 搭載車で行っています

## 開発者向け

Android Studioで本リポジトリを開き、通常のGradleビルドで動作します。

```bash
./gradlew assembleDebug
```

MEMSとの通信仕様は、公開されているMEMSFCRのドキュメントと複数の独立した実装を突き合わせ、実車での実測データも参照しながら検証しています。
