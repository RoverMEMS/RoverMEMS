MEMS Log Diagnostics
Rover Mini SPi(MEMS 1.3)の走行ログから、異常の可能性と確認ポイントを提示する無料ツール
非公式・無料・個人プロジェクト

RoverMEMS(Rover Mini MEMS 1.3診断アプリ)の姉妹ツールです。ブラウザの中だけで動作し、読み込んだログはどこにも送信されません。判定に使っているしきい値・診断ロジックの多くは MemsFCR(memsfcr.co.uk / GitHub: andrewdjackson/rosco)が公開している情報を参考にしています。

これは目安を示すツールであり、実車の点検・整備士の診断に代わるものではありません。最終判断は必ずご自身の車の状態・専門家の意見と合わせて行ってください。

はじめに: 出てくる用語の解説(タップで開閉)
サンプルデータ表示中
RoverMEMSアプリの走行ログCSV(旧10列 / 全項目の新しい形式どちらも可)を読み込めます。列が足りない場合はその項目の判定だけ自動的にスキップされます。「サンプルログを生成」は毎回ランダムな異常パターンを仕込んだ架空データを作ります(実データではありません)。

これは目安です。実車の点検・整備士の判断に代わるものではありません。
判定の基準は、MemsFCR(memsfcr.co.uk / GitHub: andrewdjackson/rosco)のプログラムと解説ページ、整備書(Haynes)の数字を元にしています。所見ごとの「根拠」は、その基準の数字の出どころです(重要度とは別)。MemsFCRの判定 = MemsFCRのプログラムと同じ基準、資料 = MemsFCRの解説ページや整備書の数字、このツール独自 = 資料に数字が無くこのツールで決めた基準、独自・実験的 = 走行中の変化を見る試験的な仕組み。資料と実車のログが食い違う場合(例: パージは実車で動いていた)は、実車のログを優先しています。
故障コード(DTC)は、意味が確認できている4ビットだけを判定に使い、それ以外は生の値の表示だけにしています。
