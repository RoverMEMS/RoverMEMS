MEMS Log Diagnostics
Rover Mini SPi(MEMS 1.3)の走行ログから、異常の可能性と確認ポイントを提示する無料ツール
非公式・無料・個人プロジェクト

RoverMEMS(Rover Mini MEMS 1.3診断アプリ)の姉妹ツールです。ブラウザの中だけで動作し、読み込んだログはどこにも送信されません。判定に使っているしきい値・診断ロジックの多くは MemsFCR(memsfcr.co.uk / GitHub: andrewdjackson/rosco)が公開している情報を参考にしています。

これは目安を示すツールであり、実車の点検・整備士の診断に代わるものではありません。最終判断は必ずご自身の車の状態・専門家の意見と合わせて行ってください。

サンプルデータ表示中
RoverMEMSアプリの走行ログCSV(旧10列 / 新34列どちらも可)を読み込めます。列が足りない場合はその項目の判定だけ自動的にスキップされます。「サンプルログを生成」は毎回ランダムな異常パターンを仕込んだ架空データを作ります(実データではありません)。

これは目安です。実車の点検・整備士の判断に代わるものではありません。
判定ロジックは MemsFCR(memsfcr.co.uk / GitHub: andrewdjackson/rosco)が実装・公開しているしきい値・技術記事に加え、旧世代ECU一般に共通する診断知見(Bosch Motronic系の「代替値(リンプホーム)」の仕組み、OBD-II診断で言う「妥当性(rationality)チェック」の考え方、ステッパー式アイドルバルブの位置の見方など、Mini/MEMSに限らず同世代の他メーカー車種でも共通して言われている内容)を組み合わせています。 Tier A = MemsFCR本体が実際に使用しているロジック、Tier B = 解説記事・他メーカーを含む一般的な整備知見、Tier C = 出典間で差があり実車確認が必要なもの、Tier T = 今回新たに考案した「1走行内の悪化傾向」検知(実験的)。
なお、この車のECU(MEMS 1.3)はMAP式(スピードデンシティ)のため、一般によく言われる「燃調トリムが張り付く=バキュームリーク」という診断はそのまま当てはまりません。この車でバキュームリークが疑わしい時は、燃調トリムではなくアイドルステッパー位置の所見を確認してください。
故障コード(DTC)は、実際に意味が確認できている4ビットのみ具体的な診断にし、それ以外は生の値のみ表示しています。
