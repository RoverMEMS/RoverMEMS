# ATOM Lite 用 BLE ブリッジ（HM-10 の代わり）

M5Stack ATOM Lite を、スマホ（RoverMEMS アプリ）と ECU 診断ポートの間の「無線の中継役」にするプログラムです。ATOM Lite は技適取得済みなので、完成品として販売できます。

アプリはこのモジュールの通信方式（Nordic UART）に対応済みなので、アプリ側の設定変更はありません。接続画面に **`RoverMEMS-xxxx`** という名前で出てきます。

## 1. 書き込み（最初の1回だけ）

1. **Arduino IDE をインストール**: https://www.arduino.cc/en/software （無料）
2. **ESP32 の追加**: Arduino IDE を開き、左側の「ボードマネージャ」（基板のアイコン）で `esp32` と検索し、**esp32 by Espressif Systems** をインストール
3. **ATOM Lite を PC に USB でつなぐ**（データ通信対応のケーブルで）
4. **このファイルを開く**: `firmware/atom_lite_bridge/atom_lite_bridge.ino`
5. **ボードの選択**: メニュー「ツール → ボード → esp32 → **M5Stack-ATOM**」
6. **ポートの選択**: 「ツール → ポート」で COM○ を選ぶ（ATOM Lite を抜き差しすると増減するのがそれ）
7. **書き込み速度**: 「ツール → Upload Speed → **115200**」（ATOM Lite は速いと失敗しやすい）
8. **書き込み**: 左上の「→」ボタン。下の欄に `Hard resetting via RTS pin...` と出れば完了

書き込み後、本体の LED が**青く点滅**していれば正常です。

うまくいかない時:
- ポートが出てこない → ケーブルが充電専用の可能性。別のケーブルで試す
- 書き込み途中で失敗 → Upload Speed が 115200 になっているか確認

## 2. 家での動作確認（車に行く前に）

1. ATOM Lite の **G26 と G32 をジャンパワイヤで直接つなぐ**（送った信号がそのまま戻ってくる「折り返し」状態。レベル変換モジュールはつながない）
2. USB 電源（PC か充電器）につなぐ → LED 青点滅
3. アプリで BLE 接続 → `RoverMEMS-xxxx` を選ぶ → LED が**緑**に変わる
4. ECU が無いので「接続エラー」になるのが正常。デバッグログに **`CA` のエコーが返っている**ことを確認できれば、無線 ⇔ 配線の中継は動いている

## 3. 車への取り付け

| ATOM Lite | レベル変換モジュール | ECU |
|---|---|---|
| 5V | HV | |
| 3V3 | LV | |
| GND | GND | （つながない。車体経由で共通） |
| G26（送信） | LV1 → HV1 | 緑線（ECU RX） |
| G32（受信） | LV2 ← HV2 | 白線（ECU TX） |

電源は車の USB-A から A→C ケーブルで。C→C ケーブルは給電されないことがあるので避ける。

## LED の意味

| LED | 状態 |
|---|---|
| 青の点滅 | スマホからの接続待ち |
| 緑 | スマホと接続中 |
| 白く一瞬光る | ECU からデータを受信 |
