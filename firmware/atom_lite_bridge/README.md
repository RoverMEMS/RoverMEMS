# ATOM Lite 用 BLE ブリッジ

M5Stack ATOM Lite を、スマホ（RoverMEMS アプリ）と ECU 診断ポートの間の「無線の中継役」にするプログラムです。ATOM Lite は技適取得済みなので、完成品として販売できます。

アプリはこのモジュールの通信方式（Nordic UART）に対応済みなので、アプリ側の設定変更はありません。接続画面に **`RoverMEMS-xxxx`** という名前で出てきます。

実車（1996年式ミニSPi / MEMS 1.3）で、接続・ライブデータ取得・エンジン始動後の自動つなぎ直しまで確認済みです。

## 必要な部品

| 部品 | 目安 |
|---|---|
| M5Stack ATOM Lite | スイッチサイエンス等で約1,800円 |
| 双方向レベル変換モジュール（秋月電子 AE-LCNV4-MOSFET） | 約200円。ATOM Lite（3.3V）と ECU（5V）の電圧の違いを吸収する |
| ジャンパワイヤ（オス－メス） | 7本 |
| USB-A → USB-C ケーブル（データ対応） | 書き込みと車での給電に使う |

## 1. 書き込み（最初の1回だけ）

1. **Arduino IDE をインストール**: https://www.arduino.cc/en/software （無料）
2. **ESP32 の追加**: Arduino IDE を開き、左側の「ボードマネージャ」（基板のアイコン）で `esp32` と検索し、**esp32 by Espressif Systems** をインストール
3. **ATOM Lite を PC に USB でつなぐ**（データ通信対応のケーブルで）
4. **このファイルを開く**: `firmware/atom_lite_bridge/atom_lite_bridge.ino`
5. **ボードの選択**: メニュー「ツール → ボード → esp32 → **M5Atom**（検索欄に atom と打つと早い）」
6. **ポートの選択**: 「ツール → ポート」で COM○ を選ぶ（ATOM Lite を抜き差しすると増減するのがそれ）
7. **書き込み速度**: 「ツール → Upload Speed → **115200**」（ATOM Lite は速いと失敗しやすい）
8. **書き込み**: 左上の「→」ボタン。下の欄に `Hard resetting via RTS pin...` と出れば完了。**初回は準備に時間がかかります**（PCによっては20〜30分）。2回目からは数分です

書き込み後、本体の LED が**青く点滅**していれば正常です。

うまくいかない時:
- ポートが出てこない → まず Windows の「デバイス マネージャー」を見る。「M5stack」に黄色の！マークが付いていればドライバー未導入なので、[FTDI 公式のドライバー](https://ftdichip.com/drivers/vcp-drivers/)を入れる。「M5stack」自体が出てこなければ、ケーブルが充電専用の可能性があるので別のケーブルで試す
- 書き込み途中で失敗 → Upload Speed が 115200 になっているか確認

## 2. 家での動作確認（車に行く前に）

1. ATOM Lite の右側のピンソケットの **G21 と G25 をジャンパワイヤで直接つなぐ**（送った信号がそのまま戻ってくる「折り返し」状態。レベル変換モジュールはつながない）
2. USB 電源（PC か充電器）につなぐ → LED 青点滅
3. アプリで BLE 接続 → `RoverMEMS-xxxx` を選ぶ → LED が**緑**に変わる
4. ECU が無いので「接続エラー」になるのが正常。デバッグログに **`CA` のエコーが返っている**ことを確認できれば、無線 ⇔ 配線の中継は動いている

## 3. 車への取り付け

家での確認で使った G21－G25 のジャンパは外してから配線します。

レベル変換モジュールは、片側（LV）が ATOM Lite 用の 3.3V、反対側（HV）が ECU 用の 5V です。同じ番号の LV1 と HV1（LV2 と HV2）が中でペアになっていて、電圧だけ変えて信号を通します。

**ATOM Lite → レベル変換モジュール**

| ATOM Lite | レベル変換モジュール |
|---|---|
| 5V（右側） | HV |
| 3V3（左側の一番上） | LV |
| G（右側） | GND（2つあるうちのどちらか1つ） |
| G21（右側・送信） | LV1 |
| G25（右側・受信） | LV2 |

**レベル変換モジュール → ECU 診断カプラー**

| レベル変換モジュール | ECU |
|---|---|
| HV1 | 緑線（ECU の受信） |
| HV2 | 白線（ECU の送信） |

- G21・G25・5V・G は本体右側のピンソケットに並んでいて、ジャンパワイヤのオス側がそのまま挿さります（G26・G32 は白い Grove 端子の中にあり、ジャンパワイヤが挿さらないため使いません）
- ECU 診断カプラーの GND にはつなぎません（車の USB 電源と車体経由で共通になっているため）
- 電源は車の USB-A から A→C ケーブルで。C→C ケーブルは給電されないことがあるので避ける
- 車の USB 電源はキーを START に回している間（セル中）に切れることが多く、そのとき接続も一度切れます。アプリが自動でつなぎ直すので、そのまま待てば数秒で表示が戻ります

## LED の意味

| LED | 状態 |
|---|---|
| 青の点滅 | スマホからの接続待ち |
| 緑 | スマホと接続中 |
| 白く一瞬光る | ECU からデータを受信 |
