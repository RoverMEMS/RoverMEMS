# Bluetooth モジュールの作り方（M5Stack ATOM Lite）

スマホと車の診断カプラーを、ケーブルなしでつなぐための小さな中継器を作ります。作ったモジュールは、RoverMEMS アプリの接続画面に **`RoverMEMS-xxxx`** という名前で表示されます。

実車（1996年式ミニSPi / MEMS 1.3）で、接続・ライブデータ表示・エンジン始動後の自動つなぎ直しまで確認しています。

## 必要な部品

| 部品 | 目安 |
|---|---|
| M5Stack ATOM Lite | [秋月電子 通販コード 117209](https://akizukidenshi.com/catalog/g/g117209/)（税込1,980円） |
| 双方向レベル変換モジュール（秋月電子 AE-LCNV4-MOSFET） | [秋月電子 通販コード 113837](https://akizukidenshi.com/catalog/g/g113837/)（税込200円）。ATOM Lite（3.3V）と車（5V）の電圧の違いを吸収する |
| ジャンパワイヤ（オス－メス） | 7本。[秋月電子 通販コード 117228](https://akizukidenshi.com/catalog/g/g117228/)（コネクター付ケーブル 20cm 40P オスメス、税込180円） |
| USB-A → USB-C ケーブル（データ対応） | 100均で購入できる。プログラムの書き込みと、車での電源に使う |
| 3ピンカプラー（オス側）＋電線（緑・白） | [延長ハーネス①](../../cable/README.md)の3ピンカプラーと対になる側 |

車の診断カプラーには、[延長ハーネス①](../../cable/README.md)を通してつなぎます（USBケーブル②と共通の部品です）。

## 1. プログラムの書き込み（最初の1回だけ）

パソコン（Windows）で行います。

### 手順0: パソコンのユーザー名を確認する

エクスプローラーを開き、`C:\ユーザー`（英語表示なら `C:\Users`）の中にある、自分のフォルダの名前を見てください。それがユーザー名です。

- **英数字だけ**（例: `taro`）→ そのまま下の「手順1」から順に進めてください
- **日本語・全角スペース・かっこが入っている**（例: `山田　太郎`）→ 手順2に**「日本語ユーザー名の設定」**が入ります。飛ばさずに行ってください（そのままだとビルドが途中で失敗し、赤いエラー文が文字化けします）

### 手順1〜9

1. **プログラムをダウンロード**: [RoverMEMS のトップページ](https://github.com/RoverMEMS/RoverMEMS)の緑の「**Code**」ボタン →「**Download ZIP**」。ダウンロードした ZIP を展開（右クリック →「すべて展開」）
   - ユーザー名が日本語の人は、展開先を **`C:\RoverMEMS-master`** のように、日本語やかっこを含まない場所にする
2. **Arduino IDE をインストール**: https://www.arduino.cc/en/software （無料）

   **【ユーザー名が日本語の人だけ】日本語ユーザー名の設定**（英数字だけの人は飛ばして手順3へ）

   Arduino IDE は作業用のファイルをユーザー名のフォルダの中に作るため、日本語が入っているとビルドに失敗します。ユーザー名を変えなくても、作業場所を英語だけのフォルダ（`C:\Arduino15`）に移せば解決します。**esp32 を入れる前に**行ってください。

   1. **Arduino IDE が開いていたら、完全に終了**する（タスクバーに残っていないことも確認）
   2. 手順1で展開したフォルダの中の `firmware\atom_lite_bridge` を開き、**`setup_for_japanese_username.bat`** をダブルクリックする
      - 「Windows によって PC が保護されました」と出たら、「**詳細情報**」→「**実行**」を押す（ダウンロードしたファイルには必ず出ます。メモ帳で開くと、中身を確認できます）
   3. 黒い画面に `Done. The following settings were written:` と出て、設定の内容が表示されれば完了。何かキーを押して閉じる
      - `You do NOT need this setup.` と出た場合は、ユーザー名が英数字だけなので設定は不要です。そのまま次へ進んでください
   4. Arduino IDE を起動して、手順3へ進む

   `.bat` がうまく動かない時は、手で設定することもできます。

   1. Arduino IDE を完全に終了し、エクスプローラーで `C:\Arduino15` というフォルダを作る
   2. エクスプローラーのアドレス欄に `%USERPROFILE%\.arduinoIDE` と入力して開く（フォルダがなければ作る）。中の **`arduino-cli.yaml`** をメモ帳で開く（見えない時は、エクスプローラーの「表示」で「隠しファイル」をオンにする）
      - ファイルが**見当たらない時**は、同じフォルダの中でメモ帳を新規作成し、ファイル名を `arduino-cli.yaml` にして保存する。保存画面で「ファイルの種類」を**「すべてのファイル」**にすると、末尾に `.txt` が付かない
   3. 中身を次のように書き換えて保存する（字下げは**半角スペース4つ**。タブや全角スペースは使わない。もとの内容は消して置き換えてよい）。打ち間違いが心配な時は、[できあがりのファイル](arduino-cli.yaml)の中身を全部コピーして貼り付けてもよい

      ```yaml
      board_manager:
          additional_urls: []
      directories:
          data: C:\Arduino15
          downloads: C:\Arduino15\staging
          user: C:\Arduino15\sketchbook
      build_cache:
          path: C:\Arduino15\build_cache
      ```

3. **ESP32 の追加**: Arduino IDE を開き、左側の「ボードマネージャ」（基板のアイコン）で `esp32` と検索し、**esp32 by Espressif Systems** の**バージョン欄を `2.0.17` にして**インストール（最新版は容量が大きく、インストールに時間がかかったり失敗したりすることがあるため、2.0.17 を使います）
   - 「Updates are available」と出ても、**「INSTALL ALL」は押さない**（最新版に上がってしまいます）
4. **ATOM Lite をパソコンに USB でつなぐ**（データ通信対応のケーブルで）
5. **プログラムを開く**: Arduino IDE の「ファイル → 開く」で、展開したフォルダの中の `firmware/atom_lite_bridge/atom_lite_bridge.ino` を選ぶ
6. **ボードの選択**: メニュー「ツール → ボード → esp32 → **M5Stack-ATOM**」（検索欄に atom と打つと早い）
7. **ポートの選択**: 「ツール → ポート」で COM○ を選ぶ（ATOM Lite を抜き差しすると増減するのがそれ）
8. **書き込み速度**: 「ツール → Upload Speed → **115200**」
9. **書き込み**: 左上の「→」ボタン。下の欄に `Hard resetting via RTS pin...` と出れば完了。**初回は準備に時間がかかります**（パソコンによっては20〜30分）

書き込み後、本体の LED が**青く点滅**していれば成功です。

うまくいかない時:
- ポートが出てこない → Windows の「デバイス マネージャー」を開く。「M5stack」に黄色の！マークが付いていれば、[FTDI 公式のドライバー](https://ftdichip.com/drivers/vcp-drivers/)を入れる。「M5stack」自体が出てこなければ、ケーブルが充電専用の可能性があるので別のケーブルで試す
- 書き込みの途中で失敗する → Upload Speed が 115200 になっているか確認
- Arduino IDE を起動しても、最初のロゴの画面から進まない → 初回は必要なファイルをダウンロードするため、数分待つ。それでも進まなければ、一度終了して（タスクバーに残っていないことも確認）起動し直す
- 書き込みの前の「ビルド」の段階で `Compilation error: exit status 1` と出て、その上の赤い行が文字化けしている → 手順2の「日本語ユーザー名の設定」を行う（ユーザー名が日本語の場合）

## 2. 家での動作確認（車に行く前に）

1. ATOM Lite の右側の穴の **G21 と G25 を、ジャンパワイヤ1本でつなぐ**（レベル変換モジュールはまだつながない）
2. USB 電源（パソコンや充電器）につなぐ → LED が青く点滅
3. アプリの接続画面で `RoverMEMS-xxxx` を選ぶ → LED が**緑**に変わり、**一瞬白く光れば**正常
4. 車につないでいないので、アプリは最後に「接続エラー」になります。これで問題ありません

## 3. 車への取り付け

家での確認で使った G21－G25 のジャンパは外してから配線します。

![配線図](wiring.svg)

レベル変換モジュールは、片側（LV）が ATOM Lite 用、反対側（HV）が車用です。同じ番号の LV1 と HV1（LV2 と HV2）が中でつながっています。

**ATOM Lite → レベル変換モジュール**

| ATOM Lite | レベル変換モジュール |
|---|---|
| 5V（右側） | HV |
| 3V3（左側の一番上） | LV |
| G（右側） | GND（2つあるうちのどちらか1つ） |
| G21（右側） | LV1 |
| G25（右側） | LV2 |

**レベル変換モジュール → ①の3ピンカプラー**

| レベル変換モジュール | 診断カプラー |
|---|---|
| HV1 | 緑（TXD） |
| HV2 | 白（RXD） |

3ピンカプラーでは、**①と同じ色どうし**（緑は緑、白は白）がつながるようにしてください。

- ATOM Lite の穴には、ジャンパワイヤのオス側がそのまま挿さります
- ①の黒（GND）にはつなぎません（3ピンカプラーの黒の位置は空けておきます）。電源を車のUSBから取るので、アースは車体を通じて共通になっているためです。モバイルバッテリーなど車と関係ない電源で動かす時だけ、ATOM Lite の G を①の黒につないでください
- 電源は車の USB-A から A→C ケーブルで取ります。C→C ケーブルは電気が来ないことがあるので避けてください
- キーを START に回している間（セル中）は車の USB 電源が切れることが多く、そのとき接続も一度切れます。アプリが自動でつなぎ直すので、そのまま待てば数秒で表示が戻ります

## LED の意味

| LED | 状態 |
|---|---|
| 青の点滅 | スマホからの接続待ち |
| 緑 | スマホと接続中 |
| 白く一瞬光る | 車からデータを受信 |
